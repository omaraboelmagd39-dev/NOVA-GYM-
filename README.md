# IRON DISTRICT — Gym Website
موقع تجريبي عربي RTL بتصميم داكن وأحمر، مبني بـ HTML وCSS وJavaScript بدون مكتبات واجهات.

## الملفات
- `index.html` الصفحة الرئيسية والأقسام.
- `css/style.css` التصميم والتجاوب مع الشاشات.
- `js/main.js` القائمة المتحركة، عدادات الأرقام، ظهور الأقسام، ونموذج واتساب.

## التشغيل
افتح `index.html` في المتصفح. يحتاج اتصالًا بالإنترنت لخط Cairo وصور Unsplash.

## قبل عرضه على عميل
- استبدل الأسماء والصور والأسعار والعنوان بمعلومات صحيحة.
- غيّر `WHATSAPP_NUMBER` في `js/main.js` إلى رقم النادي بصيغة دولية دون علامة + أو مسافات.
- اختبر جميع الأقسام والروابط على الهاتف والكمبيوتر.
- لا توحِ أن أرقام الأعضاء أو الأسعار بيانات حقيقية؛ هي تجريبية.

## النشر المجاني على GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا باسم `iron-district-gym`.
2. ارفع محتويات المجلد مع الحفاظ على هيكل الملفات، واجعل `index.html` في الجذر.
3. افتح Settings → Pages.
4. اختر Deploy from a branch، ثم `main` و`/(root)` واضغط Save.
5. بعد النشر سيكون الرابط عادة `https://YOUR-USERNAME.github.io/iron-district-gym/`.

## ملاحظات
